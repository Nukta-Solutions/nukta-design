# @nukta-solutions/tokens

## 0.2.0

### Minor Changes

- 8e210ab: Add `chart-1` … `chart-5` color tokens for data series (`fill-chart-1`, `var(--color-chart-1)`),
  with distinct hues in both modes. Each is contrast-tested at 3:1 or more against backgrounds and
  surfaces (WCAG 1.4.11).
- c9d892d: Add the `warning-emphasis` color token (`text-warning-emphasis`) for warning-colored text and
  icons on light surfaces, where plain amber is too light. Also contrast-test `success` and `info`
  as text on surfaces. Both modes pass WCAG AA.
